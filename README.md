# eSports Analytics: A Centralized Platform for Professional League of Legends Data
# Final Project for DSCI-D532 SU 2026

This project is a full-stack database application built using MySQL, Python, Flask, HTML, and CSS. It uses professional League of Legends esports data from Oracle's Elixir, which was cleaned and preprocessed before being imported into a normalized relational database.

The application allows users to browse players, teams, and champions through a simple web interface while displaying statistics generated from SQL queries, including player performance, champion usage, and team win rates. The project demonstrates database design, SQL development, data preprocessing, and web application integration.

Original data: https://oracleselixir.com/tools/downloads
Live application: https://lol-esports-database.onrender.com/

# Features
- Normalized MySQL database design
- Data preprocessing and CSV import
- Player, team, and champion pages
- Interactive data visualizations
- Searchable player database
- Team win/loss statistics
- Champion usage statistics with images
- Flask back-end with HTML/CSS front-end
